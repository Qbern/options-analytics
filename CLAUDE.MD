# Project: options-analytics

Public portfolio repo showcasing derivatives pricing and risk analytics in Python.
Audience: recruiters and hiring managers in risk, derivatives and equity research.

## Language rules
- ALL content in the repo must be in English: code, comments, docstrings,
  README, notebooks (markdown cells included), commit messages, error messages.
- Never write Spanish inside the repo.

## Code style
- Python 3.12, type hints on all public functions, docstrings explaining
  parameters and units.
- Keep code simple and readable. No over-engineering.
- Separate financial logic (src/options_analytics/) from any UI code.

## Safety
- This repo is public. Never commit API keys, .env files or personal data.

## Working style
- Before writing code, briefly state what you are going to create.
- After writing code, run the tests and show the output.
